Wallet Time Machine · Session 3 · “Every world” includes the wildcard

09 / 15

Sort each cluster on two questions: did we name it in session 1, and does it hold in every world including the wildcard? Named and holding everywhere is a no-regret move: start now. Named but holding in one world is a bet: test it cheaply. Holding everywhere but missed in session 1 is a blind spot: add it, because the futures found something our ambition did not. The rest are hedges: watch them, with a plan ready. The gap between what we wanted and what holds is often the most useful finding of the workshop.
