Bybit showed that the interface, not the key, can be the weakest link: signers saw a routine transfer while the real payload replaced the multisig implementation. Agent wallets now add a new principal that is not a person. The x402 volume figure is from Chainalysis and other trackers report different totals, so treat it as directional. The lesson is that spending policies belong on-chain or in isolated policy engines, never in the model’s own judgment.
